# INDIAN EQUITY RESEARCH — SOURCE ACCESS PROTOCOL

When researching an Indian listed company, search the following sources in the stated priority order.

## PRIMARY SOURCES

1. BSE
   https://www.bseindia.com/

   Search for:
   - Corporate announcements
   - Financial results
   - Annual reports
   - Investor presentations
   - Shareholding pattern
   - Corporate governance
   - Board meeting outcomes
   - Order wins
   - Fund raising
   - Acquisitions
   - RHP/DRHP
   - Other exchange filings

2. NSE
   https://www.nseindia.com/

   Search for:
   - Corporate announcements
   - Financial results
   - Annual reports
   - Investor presentations
   - Shareholding
   - Corporate actions
   - IPO/RHP/DRHP
   - Exchange disclosures

3. COMPANY WEBSITE

   Search:
   - Investor Relations
   - Annual Reports
   - Investor Presentations
   - Earnings/Concall transcripts
   - Press releases
   - Corporate presentations

4. SCREENER.IN
   https://www.screener.in/

   Use primarily for:
   - Revenue
   - EBITDA/Operating Profit
   - PAT
   - EPS
   - ROE
   - ROCE
   - Debt
   - Cash Flow
   - Working Capital
   - Promoter Holding
   - Pledged Shares
   - Historical ratios
   - 3-year and 5-year trends

   Screener is secondary to official filings.

## SOURCE PRIORITY

BSE/NSE official filings
>
Company official filings
>
RHP/DRHP
>
Credit-rating reports
>
Screener.in
>
Reputable financial sources
>
YouTube

Never allow a lower-priority source to override a primary source without explicitly explaining the discrepancy.

## DOCUMENT SEARCH

For every company search for the latest:

1. Annual Report
2. Investor Presentation
3. Latest quarterly results
4. Latest earnings/concall transcript
5. Latest BSE announcements
6. Latest NSE announcements
7. RHP/DRHP, if applicable
8. Credit-rating report
9. Relevant management interviews
10. Relevant YouTube videos

Then retrieve the corresponding documents for the previous three financial years.

## DATE CONTROL

Always identify:

- Document title
- Filing/publication date
- Financial period
- Source
- URL

Use the latest available document.

Do not use an old investor presentation when a newer presentation exists.

## CROSS-CHECK

Cross-check important figures whenever possible.

Examples:

Revenue:
Annual Report + Screener

Debt:
Annual Report + Credit Rating

Order Book:
Investor Presentation + BSE/NSE filing

Capacity:
Investor Presentation + Annual Report

Promoter Holding:
NSE/BSE + Screener

Management Guidance:
Investor Presentation + Concall transcript

IPO information:
RHP/DRHP + NSE/BSE

## ANTI-HALLUCINATION

Never invent:

- Customers
- Orders
- Order-book value
- Capacity
- Market share
- Project cost
- Revenue
- Margins
- Management guidance
- Future earnings
- Product contribution
- Project completion dates

If information is unavailable, state:

"Not disclosed / reliable source not found."

Clearly distinguish:

FACT
MANAGEMENT GUIDANCE
ANALYST CALCULATION
ANALYST ASSUMPTION
INFERENCE

## YOUTUBE

Search YouTube for relevant:

- Earnings calls
- Investor presentations
- Management interviews
- CEO/CFO interviews
- Industry discussions

Record:

- Video title
- Speaker
- Date
- Channel
- URL

Do not treat YouTube commentary as verified fact unless corroborated by a primary source.

## FINAL SOURCE INDEX

Every report must end with:

SOURCE INDEX

1. BSE
2. NSE
3. Company website
4. Annual Report
5. Investor Presentation
6. Concall/Transcript
7. RHP/DRHP
8. Screener.in
9. Credit-rating report
10. Relevant YouTube sources

Every important factual claim must be traceable to a source.
